Microsoft Visual C++ Runtime notice
===================================

The SoAI Windows installer downloads the official Microsoft Visual C++ x64 Redistributable from Microsoft and installs it when required. It also copies the required Microsoft-signed runtime DLLs into the SoAI installation, either from the Windows system runtime or, when Windows cannot be updated, from that same Microsoft Visual C++ Redistributable package.

The Microsoft Visual C++ Runtime components are separate third-party dependencies. They are not first-party SoAI code and are not licensed under the SoAI Source-Available License 1.0 or the SoAI commercial license.
