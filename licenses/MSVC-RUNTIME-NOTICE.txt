Microsoft Visual C++ Runtime notice
===================================

The SoAI Windows installer downloads the official Microsoft Visual C++ x64 Redistributable from Microsoft and installs it when required. It also downloads the VCLibs.VCRuntime.140 NuGet package and copies the required app-local runtime DLLs into the SoAI installation.

The Microsoft Visual C++ Runtime components are separate third-party dependencies.
